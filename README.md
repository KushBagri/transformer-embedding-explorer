# Transformer Embedding Explorer

An interactive visualization tool for understanding how transformers combine token embeddings and positional embeddings.

## Motivation

One question that always fascinated me:

If token embeddings and positional embeddings are simply added together, how does a transformer still retain positional information?

This project aims to visualize that process from first principles.
